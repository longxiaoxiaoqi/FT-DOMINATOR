## 字段映射候选

| 旧字段 | 目标业务含义候选 | 处理限制 |
|---|---|---|
| assets.id | 旧记录来源标识 | 不自动当作新型号编号或实物序列号。 |
| assets.product | 芯片型号原始名称 | 先核对别名、空格、前导零等，不能凭文本生成正式配置。 |
| assets.type | 资源类型 | 测试机是否进入库存待 Q03；旧库没有 Handler/KIT 类型。 |
| assets.model | 资源或设备的型号、规格描述 | 可能是混合文本，不能直接据此合并资源。 |
| assets.location | 地点原始名称 | 先区分工厂、仓库及厂区，再建立地点与工厂关联。 |
| assets.qty、unit | 候选库存数量和单位 | 必须核对是否一行一件、一个批次或型号总量；不按同名行直接相加。 |
| assets.status | 旧状态原文 | 状态映射另行确认，不能把维护中自动改成维修中。 |
| assets.sent_date | 旧寄送日期 | 非完整入库日期，也不是签收日期；未知占位符保留为来源信息。 |
| assets.compatible | 兼容关系说明 | 自由文本仅可作人工核对依据，不能据此断定已验证配套组合。 |
| assets.file_name | 文件名说明 | files 表当前为空；不据文件名生成实际附件、版本或下载地址。 |
| assets.note | 备注 | 保留来源，不自动解析为已确认负责人或参数。 |
| shipments.asset_id | 旧资产关联 | 需通过旧记录映射定位资源，不能直接沿用新资源主键。 |
| shipments.from_location、to_location | 来源与目标地点候选 | 需与地点映射表核对。 |
| shipments.sent_date、tracking_no | 寄送时间、物流信息 | 不补造签收时间或收货人。 |
| shipments.handler | 寄送经办人 | 不是 Handler 设备，不能映射到设备档案。 |
| shipments.note | 寄送备注 | 原文保留。 |
| files.asset_id、original_name、stored_name | 旧附件关联与路径 | 真正迁移前核查文件存在、权限与关联版本；本次没有附件行可验证。 |
| releases | 应用更新记录 | 不是图纸版本、规范版本或业务进度，不混入对应业务。 |

## 不可直接转换的关系

1. 旧资产只有单一 product 字段，不能代表全部适用芯片。
2. 旧寄送记录未保存本次寄送数量，当前资产数量不等于当时数量，无法可靠倒推出历史数量流水。
3. 旧当前位置不证明调拨已经签收，不能自动补造完整在途与签收记录。
4. 缺少 Handler、KIT、工厂 LB 规范与配置版本资料，不能从芯片名或备注猜测。
5. 若后续确定迁移，可讨论“核实当前余额作为期初，旧记录保留来源”方案，但本步未批准或执行迁移。

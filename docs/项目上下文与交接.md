## 2. 用户目标及已确认需求

- 数据库支持的内部多人 FT 资源记录平台，方便查阅、维护及跟进进度；封装厂人员不登录。
- 浏览框架：封装厂 → 芯片型号（原称产品）→ Handler → KIT；同级另一分支为测试机 → LB、Socket、DC 线。
- 封装厂层级包含 LB 规范；管理 LB 图纸、Socket 图纸、Pin 针图纸。
- 快捷入口：封装厂、芯片型号、库存总览、图纸中心、进度事项。
- 自有库存与封装厂库存统一记录；共享资源不按芯片重复累计。
- 选用第三版表格工作台视觉方向，电脑表格、手机卡片；效果图数据不是业务数据。
- 手机需要公司外访问；公司已允许图纸上云，但尚未部署公网服务。
- 用户后来明确：先搭框架，不等 Excel，资料自行逐步填写。Excel 导入和旧数据迁移延期。
- 不擅自增加功能，不覆盖真实数据；示例与测试只能进入隔离测试库。

细节规则见 `docs/需求说明.md`。同芯片可跨工厂，同厂同芯片可多套配置；文档新增版本不自动替换旧配置的版本；停用保留历史；库存变更应留下操作人、时间、原因和流水。

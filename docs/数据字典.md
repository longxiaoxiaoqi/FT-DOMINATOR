# FT 资源管理平台数据字典草案

日期：2026-09-24 · 第 02 步 · 待真实样例验证。

本文定义业务字段含义，不是数据库表设计。字段名、唯一性、必填条件与枚举均需结合实际 Excel 验证；不据此直接迁移旧库。依据为需求基线及旧库结构，不使用虚构记录补齐真实配套。

## 通用约定

- 业务编码与数据库内部标识分离；无现成编码时由系统生成，规则在第 03 步确定。
- 名称、型号、版本保留原文，保留前导零；不自动改大小写或合并近似名称。
- 未知版本不假定为 V1；空值不等同于零、已验证或不适用。
- 型号档案、配套配置、库存数量分开；配置表中重复出现的资源不重复入库。
- 创建人、创建时间、修改人、修改时间由系统记录，不用导入时间冒充历史业务时间。
- 下列“需要”仅指业务识别所需信息，最终表单必填与导入缺值处理待样例确认。

## 基础资料

| 对象 | 候选字段 | 含义与校验要点 |
|---|---|---|
| 封装厂 | 工厂编码、名称、厂区、联系人、联系方式、备注、启用状态 | 工厂与仓库不同；简称和全称建立经确认的对应，不按相似文本合并。 |
| 存放地点 | 地点编码、名称、地点类型、所属工厂、备注 | 自有仓库可无所属工厂；一个工厂可有多个地点。 |
| 芯片型号 | 型号、封装形式、尺寸、Pin 数、备注、启用状态 | 型号保留字符串；参数未知可待补，不从名称推导。 |
| 测试机型号 | 型号、品牌、参数说明、启用状态 | 型号与具体机台编号不同；设备追踪范围见 Q03。 |
| Handler 型号 | 型号、品牌、适配封装、参数说明、启用状态 | 与寄送记录中的经办人字段无关。 |
| 资源型号 | 类型、型号编码、名称、规格、版本、计量单位、备注、启用状态 | LB、Socket、DC 线、KIT；版本与图纸文件版本不是自动同义。 |
| Pin 针资料 | 规格或型号、关联 Socket、图纸关联、备注 | 第一版管理资料；不推定已授权针库存或寿命计数。 |

## 配套关系

| 对象 | 候选字段 | 含义与校验要点 |
|---|---|---|
| 工厂芯片关系 | 工厂、芯片型号、备注、状态 | 同一芯片可关联多家工厂。 |
| 测试配置 | 配置名称或编码、工厂、芯片型号、测试机型号、Handler 型号、验证状态、备注 | 同厂同芯片允许多套；不能用工厂和芯片作为唯一配置键。 |
| 配套资源 | 所属配置、资源类型、资源型号或版本、关联说明 | KIT 随 Handler 展示；LB、Socket、DC 线随测试机展示。配置中各资源的数量与可选性待真实关系确认。 |
| 规范引用 | 所属配置、工厂 LB 规范版本 | 不自动指向最新版本；关联必须属于适用工厂与范围。 |
| 验证信息 | 状态、日期、说明、依据附件 | 未验证不能默认已通过；具体枚举待确认。 |

## 库存与流转

以下以数量管理的建议方案描述，Q01、Q02、Q03、Q12 未确认前不固化实现。

| 对象 | 候选字段 | 含义与校验要点 |
|---|---|---|
| 库存余额 | 资源型号、版本、地点、状态、数量、单位 | 数量非负；一个单位口径内汇总，不直接合计件、套、台。 |
| 期初入库 | 来源批次、资源、地点、状态、数量、日期、说明 | 同一来源记录不能反复增加期初数量；去重依据在导入设计时确定。 |
| 调拨单 | 单号、来源地点、目标地点、发出日期、经办人、物流信息、备注 | 地点不能相同；经办人不是 Handler 设备。 |
| 调拨明细 | 资源型号和版本、发出数量、已签收数量、未签收数量、单位 | 已签收不超过发出；未签收为差额，不能全量发出后直接算目标库存。 |
| 签收记录 | 调拨明细、本次签收数量、签收时间、操作人、差异说明 | 支持多次签收及重复提交保护。 |
| 库存流水 | 操作类型、关联单据、资源、地点、状态、变更数量、操作人、时间、原因 | 由业务操作生成；数量调整也必须记录原因。 |
| 盘点 | 地点、资源、状态、账面数量、实盘数量、差异、原因 | 实盘数量不能直接无痕覆盖余额。 |

## 图纸和工厂规范

| 对象 | 候选字段 | 含义与校验要点 |
|---|---|---|
| 图纸档案 | 编号、名称、类别、关联资源 | 类别为 LB、Socket、Pin 针；同名文件不证明是同一份图纸。 |
| 工厂 LB 规范 | 编号、名称、所属工厂、适用测试机范围 | 全厂通用或指定范围；为工厂级资料。 |
| 文档版本 | 所属档案、版本号、状态、发布日期、变更说明、上传人和时间 | 每次版本更新保留历史；同档案版本冲突需提示。 |
| 附件 | 原文件名、存储标识、大小、类型、所属文档版本 | 文件本体与元数据分离；有文件名不代表文件存在。 |

## 进度与权限

| 对象 | 候选字段 | 含义与校验要点 |
|---|---|---|
| 事项 | 标题、类别、关联工厂或芯片或资源或配置、负责人、状态、计划完成日期 | 类别与状态待 Q05 确认；计划日期和实际完成时间不同。 |
| 更新记录 | 所属事项、进展内容、状态变更、更新人和时间、附件 | 按时间追加，不覆盖旧进展。 |
| 用户 | 账号、显示名、启用状态、角色 | 不迁移固定演示密码，不默认保留匿名访客。 |
| 操作记录 | 操作人、对象、操作类型、时间、变更摘要 | 记录关键修改与业务操作，权限范围待 Q04。 |

# 测试资源管理

## 新版 FT 资源管理平台

接手项目先读 [项目上下文与交接](docs/项目上下文与交接.md)。当前优先完善业务功能页面与录入流程，服务器部署暂停，视觉布局调整延期。

最新优先级：保证本机正常运行；服务器方案、部署、外网手机访问、Excel 导入和旧数据迁移均暂缓。

本机入口位于项目根目录：`启动FT资源管理平台.bat`、`重启FT资源管理平台.bat`、`检查本机运行.bat`。更新代码后若提示旧版本仍运行，先保存或关闭表单，再双击重启入口。重启不重建账号、不清空数据库。2026-10-15 自动停止旧进程受到执行策略拦截，当前仍待手动重启切换新版。

新版位于 `platform/`，双击 `platform/start.bat` 启动，默认访问 `http://127.0.0.1:4180`。首次创建管理员后录入资料，业务库初始为空。

已包含工厂、芯片、Handler/KIT、测试机配套资源、LB 规范、图纸版本、库存调拨、进度、内部账号及手机布局。使用与部署说明见 [platform/README.md](platform/README.md)，开发状态见 [docs/开发进度.md](docs/开发进度.md)。

新版数据与附件独立保存在 `platform/runtime/`。旧版原型和数据库未迁移、未覆盖。当前是本地可运行版本，公网访问需要另行配置云服务器与 HTTPS。

## 旧版本地原型

用于管理 LB、Socket、测试机、DC线、封装厂寄送记录和图纸附件的本地 Web 应用。

## 启动

每次电脑重启后双击 `prototype/start.bat`。启动脚本会自动运行本地服务并打开 <http://127.0.0.1:4173>。

## 账号

以下账号仅属于旧版 prototype（4173），不适用于新版 platform（4180）；新版使用自行创建的账号，没有固定默认账号。

- 管理员：账号 `admin`，密码 `admin`，拥有完整权限。
- 临时访问：无需密码，只读访问。

## 数据

- SQLite 数据库：`prototype/data/test_assets.db`
- 上传文件：`prototype/uploads/`

运行数据不会提交到 Git，请单独备份数据库和上传目录。

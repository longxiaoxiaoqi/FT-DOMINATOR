# FT 资源管理平台

独立于旧版 `prototype/` 的可运行平台。首次启动没有工厂、芯片、资源或库存示例数据，由管理员创建账号后逐步录入。

## Windows 一键启动

当前优先保证本机使用；服务器部署、外网手机访问、Excel 导入和旧数据迁移暂缓。

项目根目录可双击 `启动FT资源管理平台.bat`，也可继续使用本目录的 `start.bat`。代码更新后若已有旧服务运行，启动器会明确提示，不再把旧进程误判为新版。保存或关闭未完成表单后双击根目录 `重启FT资源管理平台.bat`（对应 `platform/restart.bat`）进行切换；它会核对进程所属项目及已知数据目录，拒绝停止其他项目或占用端口的未知程序。重启入口不会重置账号或清空资料；如有结构更新，仍会按原启动流程执行迁移。

双击根目录 `检查本机运行.bat` 可只读检查数据库完整性、附件缺失、待执行业务迁移、在线版本与数据目录匹配。命令行为 `python local_check.py`，离线数据检查为 `python local_check.py --offline`。旧服务没有版本标识时，在线匹配项会返回 false，表示未能确认匹配，不代表数据已损坏。脚本不读取密码或运行密钥、不修改业务资料。

本轮自动重启仍被执行策略 blocked by policy 拒绝，需要用户手动重启一次；未声称 4180 已切换新版。重启后可再次运行本机检查，正常时最后一项为 `"ok": true`。

双击本目录 `start.bat`。默认地址为 `http://127.0.0.1:4180`，与旧版 4173 端口分开。

首次启动会打开创建管理员的页面，填写账号、姓名和至少 10 位密码。启动链接中带有仅保存在本机的初始化密钥；创建账号后该密钥不能再次创建管理员。不要把初始化链接分享给其他人。

若手动访问页面提示输入初始化密钥，可在本机 `runtime/initial-setup.txt` 查看。没有固定默认账号和密码。管理员可在“用户管理”创建管理员、编辑人员和只读人员；每人使用独立账号。

本机已建立 `.venv` 环境。换电脑时安装 Python 3.11 或以上，执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\start.ps1
```

## 建议录入顺序

### 封装厂工作台

封装厂页采用蓝灰色的列表/详情分栏布局：左侧搜索、切换工厂或包含停用记录，右侧查看芯片配置、LB 规范、工厂库存及进度。切换工厂时保留当前页签并清空详情筛选，左侧工厂筛选与右侧内容查询相互独立；顶部导出按左侧工厂列表条件生成。停用工厂仍能查历史和编辑恢复，但不提供新增关联资料入口。

手机上工厂列表显示在详情上方，其他列表继续采用手机卡片；所有页面的侧栏、标题、筛选、表格、按钮和弹窗统一为同一蓝灰色样式。更新后保存未完成表单，再刷新页面即可使用，无需为前端更新重启服务。

### 资料录入

1. **封装厂**：录入工厂名称、厂区及联系方式。
2. **芯片型号**：录入型号及封装参数。
3. **基础资料 → 资源型号**：录入 Handler、KIT、测试机、LB、Socket、DC 线，以及需要独立登记的 Pin 针规格。
4. **基础资料 → 存放地点**：录入自有仓库和各工厂仓库，工厂仓库选择所属工厂。
5. **封装厂 → 芯片型号 → 新增测试配置**：选择芯片和配套资源，可先保存“待补全”。
6. **图纸中心**：先建档案，再进入档案上传版本及附件；LB 规范选择封装厂，图纸选择对应资源。配置可以固定引用所用版本。
7. **库存总览**：登记入库、调拨、状态调整或盘点。在“调拨与签收”登记到货，支持分批签收。
8. **进度事项**：录入事项与负责人，再追加进展和照片。手机可完成同样操作。

停用不删除档案和历史。资源已被库存、图纸或配置引用后，型号、类型、版本和计量单位不可直接改写；新增资源版本后调整后续配置。

## 当前功能与规则

- 五个快捷入口，以及基础资料、用户管理和操作记录。
- 工厂、芯片、设备、配套资源的录入、编辑、搜索及停用。
- 同厂同芯片多套测试配置；Handler/KIT 与测试机/LB/Socket/DC 线分支；工厂级 LB 规范。
- LB、Socket、DC 线、KIT 按型号、版本、地点、状态和数量管理。测试机、Handler、Pin 针管理资料，不进行库存操作。
- “待补全”配置允许缺资源；“已通过”需补齐全部六类设备与配套资源。特殊测试流程如不需要某类资源，可后续调整规则。
- 库存入库、盘点、报废、状态变更、发出与分批签收；事务、数量检查、请求去重及修改冲突提示。
- 图纸版本和附件；发布与作废；PDF、PNG、JPG、WebP 可预览，其他允许格式下载。单文件上限 30 MB，每次最多 10 个。
- 事项负责人、计划日期、状态和追加进度历史；支持附件上传。
- 密码哈希、会话登录、CSRF 防护、登录失败限制；静态目录和私有附件隔离。
- 手机卡片式表格和菜单；后台与电脑共用数据。
- 列表提供中文 CSV 导出，可用 Excel 打开；关联列显示工厂、资源型号、版本和负责人名称。导出按当前已应用的筛选条件生成，不额外包含隐藏的停用记录。完整 Excel 导入向导后续实现。

## 关联搜索与筛选

库存余额、调拨和库存流水还支持按具体资源型号及地点组合查询；调拨地点匹配来源或目标。查询后导出使用相同条件，顶部汇总仍为全局汇总。停用资源/地点的历史记录仍可查询。

库存行可直接发起调拨、状态调整、盘点及报废，自动带入资源、地点和状态；表单显示打开时的账面余额，盘点预填账面数量，保存时仍校验库存和并发变化。关联档案已停用的库存行保留查询，但不显示新增操作入口。

点击调拨单号可查看来源、目标、发出说明、发出人和时间、在途数量，以及全部发出/分批签收流水；未签收完且有编辑权限时可继续登记签收。库存流水也可以直接打开关联调拨单。

资源详情包含直接关联该资源的进度事项，可新增并带入资源。事项详情支持编辑和跳转关联工厂、芯片、资源及配置；仅选择配置的历史事项会在展示、搜索和导出时带出配置所属芯片，不回写原记录。

本轮包含后端查询修改，需要重启已有本地服务后完整生效；仅刷新网页不能加载新后端。2026-10-15 自动重启操作被执行策略拦截，4180 保持原进程运行，尚未切换。

在列表输入关键词后点击“查询”，支持匹配记录本身和相关名称：例如芯片列表可搜索关联工厂，进度事项可搜索负责人或配置所属工厂。工厂详情中的配置、规范、库存和进度也支持查询。

类型、封装厂和状态可以组合筛选，点击“重置”恢复默认。停用档案默认隐藏，勾选“包含停用”后再查询。库存、调拨和流水保留历史记录，不通过档案停用状态隐藏数量。

“导出筛选结果”导出当前已应用的查询条件；输入框修改后需先点查询。库存页顶部概况始终是全局汇总，不随下方明细筛选改变。调拨工厂筛选匹配来源或目标所属工厂；资源的关联工厂来自启用配置或有余额库存地点。

## 技术实现

采用 Django 5.2、Waitress、原生 HTML/CSS/JavaScript。为了先交付无需 Node 构建即可运行的独立程序，本轮未引入 Vue，也未改动旧 React/Vinext 脚手架。业务逻辑与 JSON 接口分离，可继续演进前端。

默认数据库为独立 SQLite：`runtime/ft.sqlite3`；附件为 `runtime/uploads/`。PostgreSQL 可通过下面的环境变量启用，但本轮只实测 SQLite，不声称 PostgreSQL 环境已通过集成验证。

## 手机与部署

云部署模板和操作步骤见 [部署与验收](deploy/README.md)。`compose.production.yaml` 提供独立 HTTPS 入口；本地仍使用原启动方式。服务器、域名和 Docker 运行验收尚未完成。

**当前默认只有本机可访问，尚未配置公网地址。** 完成云部署后，手机在公司外通过同一 HTTPS 地址登录。

同一局域网临时试用可设置 `FT_HOST=0.0.0.0`，并把本机 IP 添加到 `FT_ALLOWED_HOSTS`，再经公司允许的防火墙规则访问 4180 端口。公网不要直接暴露无 HTTPS 的服务。

云服务器提供 `Dockerfile` 与 `compose.yaml`：先配置域名、HTTPS 反向代理和持久化存储，再运行。生产环境要求：

| 环境变量 | 含义 |
|---|---|
| FT_HOST / FT_PORT | 监听地址和端口，默认 127.0.0.1 / 4180 |
| FT_DATA_DIR | 数据与附件目录，默认本目录 runtime |
| FT_ALLOWED_HOSTS | 允许访问的主机名，逗号分隔；生产必须设置域名 |
| FT_HTTPS | HTTPS 反向代理就绪后设为 1，启用安全 Cookie 和 HTTPS 跳转 |
| FT_TRUST_PROXY | 仅在可信反向代理覆盖转发头时设为 1 |
| FT_CSRF_ORIGINS | 可信 HTTPS 来源，如 https://ft.example.com |
| FT_SECRET_KEY | 可通过部署环境注入；未设置时在本地生成并保存 |
| FT_POSTGRES_NAME / USER / PASSWORD / HOST / PORT | 全套 PostgreSQL 连接配置；另安装 psycopg[binary] |

附件当前采用云服务器可挂载的私有磁盘，不是已接入的对象存储服务。公网服务器、域名、HTTPS、对象存储接入和生产备份调度仍需在确定实际环境后部署验证。

## 备份与恢复

运行数据不提交 Git。**备份数据库和附件必须配套**；停止服务后执行 `python backup.py`，备份写入 `runtime/backups/时间戳/`，再将备份复制到独立受控存储。

恢复时停止服务，先另行备份当前目录，再将选定备份中的 `ft.sqlite3`、`uploads/` 与密钥文件复制到目标 runtime，运行迁移并启动。不要覆盖旧版 prototype 数据。不能只恢复数据库而丢弃上传文件。

备份包含资料和密钥，应限制访问。管理员误操作账号或遗忘密码可在服务器使用 `manage.py changepassword 账号` 恢复访问。

新版备份自动生成校验清单并检查 SQLite 完整性。可运行 `python backup.py --verify 备份目录`；恢复命令 `python backup.py --restore 备份目录 --to 新目录` 仅允许写入尚不存在的目录，拒绝覆盖。操作与旧备份兼容限制见 [部署说明](deploy/README.md)。备份仍要求先停止服务。

生产 Compose 环境还可使用 `python backup_compose.py --destination 独立备份目录`，自动串联停服、备份、恢复服务、复制和校验；仅供未来服务器部署使用，本机没有安装或启用定时任务。Docker 实机验收尚未完成。

## 暂未包含

Excel 导入按用户最新要求不作为前置，本轮未实现导入向导。复杂审批、采购财务、针寿命、企业微信、原生 App 仍不在本轮范围。外网访问必须完成云部署，不能通过本机链接在外部手机直接访问。

### 未保存提醒

录入弹窗修改文字、选择项、数量或附件后，点击取消、右上角关闭、Esc、跳转其他页面或切换录入对象时，会确认是否放弃；取消离开会保留原输入。刷新或关闭标签页时使用浏览器自带的离开提醒。未修改、改回原值、初始联动预填和保存成功后不提醒。

保存中暂不允许关闭或切换，保存失败保留表单及附件。保存时如登录失效，会提示保留当前页，在新标签页重新登录后再重试。此功能仅提醒和保留当前页面内容，不自动保存草稿到数据库或浏览器存储。

本项为前端更新，刷新页面即可使用；已核对本机 4180 返回的脚本与磁盘新版一致。版本指纹包含静态文件，因此服务健康接口的启动时版本标识会在下次常规重启时同步，但不影响刷新后启用本项功能。

### 关联录入

芯片详情包含测试配置、配套资源、图纸与规范、进度事项四个页签，支持搜索、工厂筛选和包含停用。跨工厂配置显示所属工厂，共用资源去重展示，点击资源查看地点库存。图纸来自配套资源，规范来自配置实际采用的版本；进度包含直接关联该芯片及经测试配置关联的事项，新建事项自动带入当前芯片。工厂规范不会因同属工厂就全部混入芯片详情。

测试配置详情可直接打开所属工厂、芯片及设备资源；点击规范/图纸版本，查看该配置实际引用版本的状态和附件，也可进入文档全部版本。历史作废引用仍可查看，不自动切换新版。配置详情同时显示启用的关联事项，编辑人员可从启用配置新增事项，自动带入配置、工厂与芯片；只读人员没有新增入口。

测试配置先选工厂、芯片和设备，再选配套资源。规范列表跟随封装厂，LB 图纸跟随 LB，Socket / Pin 针图纸跟随 Socket。切换上级选择会清除不适用的选项并提示，点击保存后才写入；取消可放弃。资源列表仅按类型筛选，兼容性仍需实际验证。

已作废版本、停用文档的版本不能新增引用；已有配置保留历史版本，不自动替换为新版。文档类别决定显示工厂或资源归属。进度事项选择测试配置时带入该配置的工厂和芯片，也可不选配置，独立创建事项。
